### lambda表达式
`[capture](parameters) -> return_type { body }`

[capture]：捕获列表（决定如何访问外部变量）
(parameters)：参数列表（类似普通函数）
-> return_type：返回类型（可省略，编译器自动推导）
{ body }：函数体

`捕获列表：`
[]	不捕获任何外部变量	 [](){}
[=]	值捕获所有用到的外部变量   [=]{ return x + y; }
[&]	引用捕获所有用到的外部变量	[&]{ x++; }
[x]	值捕获 x	[x]{ return x * 2; }
[&x]	引用捕获 x	   [&x]{ x = 10; }
[x, &y]	混合捕获	   [x, &y]{ y += x; }
[=, &z]	值捕获所有 + 引用捕获 z	[=, &z]{ z = x + y; }
[&, x]	引用捕获所有 + 值捕获 x	[&, x]{ y = x; }

！不能重复捕获同一个变量（如 [x, x] 错误
！引用捕获需确保变量生命周期长于 Lambda（出现局部变量时候）

`举例：`
>使用 Lambda表达式定义简单的匿名函数

    定义一个 Lambda表达式，计算两个数的和
    auto plus = [] (int a, int b) -> int { return a + b; };
    // 调用 Lambda表达式
    cout << plus(3, 4) << endl; // 输出 7

>使用 Lambda表达式捕获外部变量

    int x = 10;
    int y = 20;
    // 定义一个 Lambda表达式，按值捕获 x 和 y
    auto add = [x, y] () -> int { return x + y; };

>使用 Lambda表达式作为函数参数

struct Item
{
    Item(int aa, int bb) : a(aa), b(bb) {}
    int a;
    int b;
};
// 使用 Lambda表达式，根据 Item 中的成员 a 升序排序
    sort(vec.begin(), vec.end(), [] (const Item& v1,const Item& v2) { return v1.a < v2.a; });
// 使用 Lambda表达式，打印 vec 中的 Item 成员
    for_each(vec.begin(), vec.end(), [] (const Item& item) { cout << item.a << " " << item.b << endl; });

>使用 Lambda表达式作为函数返回值

    auto make_adder(int x)
    {
        return [x] (int y) -> int { return x + y; };
    }
